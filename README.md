# DL

This repository contains a simple deep learning exploration project built around a Jupyter Notebook.

## Contents

- `BasicDL.ipynb` - main notebook for experiments and model development.

## Getting Started

1. Create a virtual environment:
   ```bash
   python -m venv .venv
   ```
2. Activate it:
   - Windows PowerShell:
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```
   - Windows CMD:
     ```cmd
     .\.venv\Scripts\activate.bat
     ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

> If `requirements.txt` does not exist yet, add the packages you need for your notebook.

## Notes

- Use Jupyter or JupyterLab to run `BasicDL.ipynb`.
- Keep checkpoint files excluded by the included `.gitignore`.
